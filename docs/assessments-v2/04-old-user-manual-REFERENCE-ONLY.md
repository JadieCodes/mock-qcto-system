User Manual

      QCTO

Assessments Domain
   Introduction

   This manual provides step-by-step instructions for using the Assessments Domain
   within the system. The process covers creating QASA Addendum applications (both
   pass and fail scenarios), multi-level internal review (ASD, Deputy Director, CEO, AIC),
   evaluation, approval letter drafting, and then two parallel paths:

         ● EISA Path (Passed Gate Evaluation) – For existing qualifications
         ● FISA Path (Failed Gate Evaluation) – For new qualifications requiring document
            upload

   Both paths eventually converge into site visit and monitoring.

   Note: You will be provided with two sets of credentials:

         ● External Domain Password :AssessPass123
         ● Internal Domain Password :
                ○ Username : Assessment
                ○ Password : AssessmentDomain

   Getting Started

   When you open the testing link, you will see two portal options:

Portal                                      Purpose

Profiles Portal                             For External Users

Departments Portal                          For Internal Users
Part 1: External User Workflow (Profiles Portal)

Step 1: Create an External Profile

   1. Click on Profiles Portal
   2. Click on Create Profile
   3. Fill in dummy information to simulate an external user
   4. Click Create Profile
   5. You will be greeted by a My Profile page displaying all entered information

Tip: You can use the username and password you set to log back in later.
Part 2: External User - Create QASA Applications

Step 1: Log into External Portal

   1. Log into the Profiles Portal
   2. Click on the Assessments Domain
   3. Enter the password provided

You will be directed to the QASA Addendum Submission section in the side navigation.
Step 2: Select Quality Partner Role

  1. Go to the user dropdown and select Quality Partner

Step 3: Create PASS Application (Existing Qualification)

  1. Click the New Applications button
  2. A modal will open - fill in the information
  3. Click Run Gate Evaluation
  4. Choose the Pass option
  5. Click Submit QASA Application to submit to the Internal side
Step 4: Create FAIL Application (New Qualification)

  1. Click New Applications button again
  2. Fill in the details
  3. Click Run Gate Evaluation
  4. Choose the Fail option
  5. You will need to upload 3 documents
  6. Click Submit QASA Application to submit to the Internal side

Step 5: Log Out of External Portal

  1. Click Logout
Part 3: Internal User - QASA Management Initial Review

Step 6: Log into Internal Portal

   1. Log into the Departments Portal
   2. Click on the Assessments Domain
   3. Enter the login passwords provided

You will be directed to the QASA Management section.
Step 7: View Submissions

The 2 newly submitted applications will be listed in the QASA Addendum Submissions
tab table.

   1. Go to the user dropdown and select ASD (Assistant Director)

Step 8: Process Both Applications (Repeat for each)

⚠️ Important: Perform the following steps for BOTH applications. The instructions
below explain one application - repeat for the other.

Step 8.1: ASD - Upload Acknowledgement Letter

   1. Click the View button in the table to open the modal
   2. Click Upload Acknowledgement Letter
   3. Click Submit to Deputy Director
Step 8.2: Deputy Director - Review and Evaluate

  1. Go to the user dropdown and select Deputy Director
  2. Click the View button to open the modal
  3. Click Review and Evaluate
  4. Tick all of the boxes
  5. Click Save and Forward to CEO
6. Open the modal again
7. Click Send to CEO
Step 8.3: CEO - Review and Approve

  1. Go to the user dropdown and select CEO
  2. Click the View button to open the modal
  3. Click Review and Evaluate
  4. Tick all of the boxes
  5. Click Save Approval

  6. Open the modal again
  7. Click Approve and Send to Quality Partner
Your application will now move to the QASA Evaluation tab.

Part 4: Internal User - QASA Evaluation Workflow

Step 9: ASD - Complete Evaluation Checklist

   1. Go to the user dropdown and select ASD
   2. Click the View button to open the modal
   3. Click Complete Evaluation Checklist
4. Complete the digital form
5. Click Generate Evaluation Report

6. In the evaluation report modal tab, scroll down and fill in the rest of the
    information
7. Click Positive - Send to Deputy Director
Step 10: Deputy Director - Review and Send to AIC

  1. Go to the user dropdown and select Deputy Director
  2. Click the View button to open the modal
  3. Click Review and Send to AIC
  4. Tick all of the boxes

Step 11: AIC - Review and Approve to CEO

  3. Click Review and Approve to CEO

  6. Click Send to CEO
Step 12: CEO - Final Review and Sign Outcome Letter

  1. Go to the user dropdown and select CEO

  4. Tick all of the boxes

  6. Click Return to ASD

Step 13: ASD - Send to QASA Application Approval

  1. Go to the user dropdown and select ASD

Step 15: Deputy Director - Review Approval Letter

  1. Go to the user dropdown and select Deputy Director

  1. Go to the user dropdown and select CEO

  4. Tick all of the boxes

  6. Click Return to ASD

  1. Go to the user dropdown and select ASD

  3. Click Submit to QP Portfolio

Part 6: EISA Path (Passed Application - Existing
Qualification)

Step 18: External - Populate EISA Validation Schedule

   1. Log out of Internal portal
   2. Log into External portal (Profiles Portal)
   3. Go to the EISA Validation section in the side navigation
   4. Select Quality Partner from the dropdown
   5. Click the View button to open the modal
   6. Click Populate EISA Validation Schedule
   7. Enter the information
   8. Click Submit Schedule to Internal
Step 19: Log Out of External Portal

  1. Click Logout

Step 20: Internal - EISA Validation Processing

Step 20.1: ASD - Liaise with QP

  1. Log into Internal portal (Departments Portal)
  2. Go to the EISA Validation section in the side navigation
  3. Select ASD from the dropdown
  4. Click the View button to open the modal
  5. Go to the Liaise with QP tab - fill in the information
  6. Go to the Instrument Validation tab - complete that information
  7. Click Send to Deputy Director
Step 20.2: Deputy Director - Review and Approve

  1. Select Deputy Director from the dropdown
  2. Click the View button to open the modal
  3. Go to the DD Review and Outcome tab
  4. Complete the information
  5. Click Approve and Send to EISA Registration
Step 21: External - EISA Registration

  1. Log out of Internal portal
  2. Log into External portal (Profiles Portal)
  3. Go to the EISA Validations section in the side navigation
  4. Select SDP from the user dropdown
  5. Click the View button to open the modal
  6. Go to the EISA Registration tab
  7. Complete the information
  8. Select the category:
          ○ EISA Trades
          ○ EISA Non-Trades
  9. Click Send to Registration
The application will move to the EISA Registration section in either the Trades or
Non-Trades tab based on your category
Step 22: Internal - Process Registration

  1. Log out of External portal
  2. Log into Internal portal (Departments Portal)
  3. Go to the EISA Trades or EISA Non-Trades section in the side navigation (based
      on category)
  4. Select Assistant Director from the user dropdown
  5. Click the View button to open the modal
  6. Go to the Trades Processing tab
  7. Click Mark Documentation as Validated
  8. Enter the registration number
  9. Click Create Registration
  10.Click Mark as Submitted to QP
Step 23: External - Send EISA Notification

  1. Log out of Internal portal
  2. Log into External portal (Profiles Portal)
  3. Go to the EISA Registration section in the side navigation
  4. Select Quality Partner from the dropdown
  5. Click the View button to open the modal
  6. Go to the Registration Docs tab
  7. Click Send EISA Notification
The application will move to the Site Visit and Monitoring section in the side navigation,
under the Notifications and Approvals tab.
Part 7: Site Visit and Monitoring (Both Paths Converge)

Step 24: Internal - Incoming Requests

  1. Log out of External portal
  2. Log into Internal portal (Departments Portal)
  3. Go to the Site Visit and Monitoring section in the side navigation
  4. The application will be listed in the Incoming Requests tab
  5. Select Assistant Director from the user dropdown
  6. Click the View button to open the modal
  7. Click Move to Planning and Scheduling
Step 25: Internal - Planning and Scheduling

The application will now be in the Planning and Scheduling tab.

   1. Click the View button to open the modal
   2. Go to the Planning and Scheduling tab in the modal
   3. Enter the information
   4. Click Save Plan and Submit for Review
Step 26: Internal - Plan Approval Workflow

Step 26.1: Deputy Director - Recommend

  1. Select Deputy Director from the dropdown
  2. Click Recommend to Domain Director

Step 26.2: Domain Director - Approve

  1. Select Domain Director from the dropdown
  2. Click Approve Plan
The application will move to the Site Visit Execution tab.

Step 27: Internal - Book Site Visit

   1. Select Sub Domain Admin from the user dropdown
   2. Click the View button to open the modal
   3. Go to the Site Visit Execution tab
   4. Click Book Site Visit
Step 28: Internal - Complete Evaluation

  1. Select Deputy & Assistant Director from the user dropdown
  2. Click the View button to open the modal
  3. Go to the Site Visit Execution tab
  4. Complete all of the information
  5. Click Finalize Evaluation Report
  6. Click Send Results to Quality Partner
Step 29: External - Submit Approved Results

  1. Log out of Internal portal
  2. Log into External portal (Profiles Portal)
  3. Go to the Site Visit and Monitoring section > Reports and Outcome tab
  4. Select Quality Partner from the dropdown
  5. Click the View button to open the modal
  6. Go to the Submit Approved Results tab
  7. Complete the Facilitator and Learner Questionnaire
  8. Click Submit Approved Results to Assessment Domain
Step 30: Internal - PEM Report

  1. Log out of External portal
  2. Log into Internal portal (Departments Portal)
  3. Go to the Site Visit and Monitoring section > Approvals and Outcomes tab
  4. Select Assistant Director from the user dropdown
  5. View the modal and go to the PEM Report tab
  6. Complete the information
  7. Click Submit to Deputy Director
Step 31: Internal - Final PEM Recommendation

   1. Select Deputy Director from the dropdown
   2. Open the modal
   3. Recommend the PEM Report

This completes the EISA process.

Part 8: FISA Path (Failed Application - New Qualification)

Step 32: Internal - FISA Standards Processing

For the failed application that follows the FISA route:

   1. In the Internal portal, go to the FISA Standards section in the side navigation
Step 32.1: Deputy Director - Allocate to ASD

  1. Select Deputy Director from the dropdown
  2. Click the View button to open the modal
  3. Click Allocate to ASD

Step 32.2: ASD - Final Evaluation

  1. Select ASD from the user dropdown
  2. Click the View button to open the modal
  3. Go to the Final Evaluation tab
  4. Complete the information
  5. Click Submit to Director and Team
Step 32.3: Director and Team - Review

  1. Select Director and Team from the user dropdown
  2. Click the View button to open the modal
  3. Go to the Review Checklist tab
  4. Tick all of the boxes
  5. Click Submit to AIC

Step 32.4: AIC - Review

  1. Select AIC from the user dropdown
  2. Click the View button to open the modal
  3. Go to the Review Checklist tab
  4. Tick all of the boxes
  5. Click Submit to Qualifications Development
Step 32.5: Qualifications Development - Approve

  1. Select Qualifications Development from the user dropdown
  2. Click the View button to open the modal
  3. Go to the Review Checklist tab
  4. Tick all of the boxes
  5. Click Approve and Return to Deputy Director

Step 32.6: Deputy Director - Complete and Move to External

  1. Select Deputy Director from the user dropdown
  2. Click the View button to open the modal
  3. Click Mark Complete and Move to External
Step 33: External - Validation of FISA

  1. Log out of Internal portal
  2. Log into External portal (Profiles Portal)
  3. Go to the Validation of FISA section in the side navigation
  4. Select SDP from the dropdown
  5. Open the view modal
  6. Go to the Upload Instrument tab
  7. Upload the document
  8. Click Submit Instrument to Assistant Director
Step 34: Internal - FISA Validation Workflow

Step 34.1: Assistant Director - AD Allocation

  1. Log out of External portal
  2. Log into Internal portal (Departments Portal)
  3. Go to the Validation of FISA section in the side navigation
  4. Select Assistant Director from the user dropdown
  5. Click the View button to open the modal
  6. Go to the AD Allocation tab - complete information
  7. Click Submit to ASD for Validation
Step 34.2: ASD - Conduct Validation

  1. Select ASD from the dropdown
  2. Click the View button to open the modal
  3. Go to the Conduct Validation tab - complete information
  4. Click Submit EISA Report to Deputy Director
Step 34.3: Deputy Director - DD Review

   1. Select Deputy Director from the dropdown
   2. Click the View button to open the modal
   3. Go to the DD Review tab - complete information
   4. Click Submit and Notify SDP

Step 35: Continue to Site Visit and Monitoring

The process will now follow the same steps as the EISA process from the Site Visit and
Monitoring section onwards (Steps 24-31).
