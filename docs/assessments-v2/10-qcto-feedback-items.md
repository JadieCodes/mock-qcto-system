- Ref numbers are the v3 comparison refs: 1.x = outstanding from the original change request, 2.x = linked to an original change request with new detail, 3.x = new requests. Each ref is unique.

## Role and naming rules from QCTO (apply everywhere)

- "QSA" must read "QASA" everywhere.
- QPs do not apply for a QASA; they SUBMIT a developed QASA for evaluation and approval.
- No headings or labels that refer to teams (e.g. "QSA Evaluation Team"); use the roles that act: ASD, DD, Director (Office), CD, CEO.
- "ASD" and "Assistant Director" are the same role. "Director and team" must read "Director Office".
- Remove on-screen developer notes and system statements (e.g. "PM-09 — not in the change request register yet", "RPL monitoring items in Site Visits come from the registration, not from Confirmation", "a separate section from EISA Registration; SDPs cannot see this section", "each QASA can only have one validation", "Registrations submitted by an SDP will appear here.").
